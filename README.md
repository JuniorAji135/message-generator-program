# Message Generator Project

## What is the Project About?

For this project, I will build a message generator program. Every time a user runs the program, they should get a new, randomized output. The message that it outputs will be made up of at least three different pieces of data.

The messages it should output randomly are based on the player you get for your fantasy football team, as follows:
